# Caal Massagens — Sistema de Agendamento

Sistema web desenvolvido para facilitar o gerenciamento de agendamentos de um espaço de massagens, com página pública e painel administrativo.

## Sobre o projeto

O Caal Massagens foi desenvolvido com o objetivo de digitalizar parte do processo de agendamento, oferecendo uma experiência simples para clientes e uma ferramenta administrativa para o profissional.

## Funcionalidades

- Página pública de apresentação dos serviços.
- Solicitação de agendamentos via WhatsApp.
- Painel administrativo com acesso restrito.
- Cadastro manual de agendamentos confirmados.
- Integração com Google Agenda.
- Criação automática de eventos no calendário.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Supabase
- Google Calendar API
- OAuth 2.0
- Netlify
## Integrações

**Supabase:** utilizado na estrutura de autenticação e no gerenciamento dos dados necessários à integração.

**Google Agenda:** permite registrar automaticamente os agendamentos confirmados no calendário.

**Netlify:** utilizado para hospedagem e publicação da aplicação.

## Objetivo acadêmico e profissional

Projeto desenvolvido como experiência prática de desenvolvimento web, integração entre serviços e aplicação de soluções digitais para necessidades reais de um negócio.
